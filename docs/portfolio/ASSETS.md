# Recursos gráficos y permisos

Estado: **permisos de publicación y redistribución pendientes de verificación humana**. Este documento es un inventario técnico, no una licencia ni una autorización.

| Recurso | Ubicación o referencia | Estado |
| --- | --- | --- |
| Fotografías de productos, logos y marcas | `InitializrSpringbootProject/src/main/resources/static/uploads/` | Origen, autor y permiso individual no acreditados en el repositorio |
| Capturas de la demo | `docs/portfolio/screenshots/` | Aplicación real con datos de ejemplo; contienen imágenes de producto cuyos permisos siguen pendientes |
| Imagen de respaldo | Referencias a Unsplash en templates/estilos | Una referencia al proveedor no acredita permiso sobre cada imagen |
| Fuentes, iconos y librerías web | POM y enlaces CDN en templates | Verificar avisos y licencias de las versiones y recursos efectivamente distribuidos |
| Diseño, texto y código académico | Historial compartido | Confirmar créditos y autorizaciones de los participantes |

No se eliminaron ni sustituyeron unilateralmente imágenes de autoría incierta. No se añadió una licencia global. Las marcas visibles son recursos del material existente; no implican relación comercial ni clientes del proyecto.

Las capturas locales se revisaron visualmente: muestran datos ficticios y cuentas `fitforge.example`, sin cookies, tokens ni paneles del navegador. Se recortó el pie de página para omitir datos de contacto de ejemplo no verificados. Sus originales se conservan en evidencia privada externa; no forman parte del repositorio.

La revisión debe resolver estos permisos antes de una publicación. Que el código compile, que las pruebas pasen o que una imagen esté públicamente disponible no concede derechos de redistribución.
